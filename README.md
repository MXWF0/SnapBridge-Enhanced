# SnapBridge-Enhanced
SnapBridge Enhanced是一款非官方的尼康相机安卓增强配套应用，更快的连接速度、更可靠的自动照片传输、更好用的远程拍摄体验，以及更简洁、更便捷的用户体验。/SnapBridge Enhanced is an unofficial enhanced Android companion for Nikon cameras, focused on faster connection, more reliable automatic photo transfer, improved remote shooting, and a cleaner, more convenient user experience.
