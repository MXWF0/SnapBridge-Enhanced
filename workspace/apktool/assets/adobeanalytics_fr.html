Collecte des données d'utilisation par Adobe Analytics

Cette application utilise Adobe Analytics, un service fourni par Adobe Inc., pour collecter et analyser les données d'utilisation permettant d'apporter des améliorations de façon continue.

Cette application utilise des identifiants pour les appareils mobiles (y compris les identifiants de publicité iOS et Android) ainsi que des technologies similaires aux cookies pour faire fonctionner ces outils d'analyse.

Ces outils d'analyse collectent les types de données suivants. Ces données sont collectées sous une forme ne permettant pas d'identifier des utilisateurs individuels.

  1. Votre position et vos actions lorsque vous utilisez l'application
  2. Votre activité de navigation
  3. Des informations sur votre appareil (y compris le type d'appareil et de navigateur, l'identifiant de l'annonce, le système d'exploitation, la vitesse de connexion et les paramètres d'affichage)
  4. Votre adresse IP (ou une partie de votre adresse IP, selon la configuration de votre solution), qui peut être utilisée pour déterminer votre position approximative
  5. Les informations de position de votre appareil mobile

Pour obtenir plus d'informations sur la manière dont Adobe utilise les données collectées par l'application, veuillez consulter les Règles de confidentialité d'Adobe.

Les utilisateurs ayant autorisé la collecte et l'analyse des données par Adobe Analytics peuvent retirer leur consentement et désactiver la fonctionnalité Adobe Analytics. Pour ce faire, veuillez suivre les instructions suivantes.

Sélectionnez « Application » > « Options de l'application » > « Analyser les données d'utilisation »* et décochez « J'accepte ».
